## Environments and Technologies Used
- OracleVM VirtualBox (7.0.16_Ubuntur162802)
- Active Directory Domain Services
- STIG Viewer 3.7

## Operating Systems Used
- Windows Server 2022 (21H2)
- Windows 11 (24H2)
